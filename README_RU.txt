Burrata Calculator Web 1.13.22

Версия 1.13.22: в разделе «Начинка» поле «Партии» необязательное и для Классики, и для Трюфеля. Если оставить его пустым, количество партий автоматически рассчитывается по заявке в кг. Подпись поля сокращена до «Партии». Можно заполнять только один вид продукта или оба одновременно; остальные расчёты и логика коробок сохранены.
