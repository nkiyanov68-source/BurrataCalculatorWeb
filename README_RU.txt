Burrata Calculator Web 1.13.32

Версия 1.13.32: принудительное обновление веб-кэша для пользователей.
- новый Service Worker сразу активируется и удаляет старые кэши Burrata Calculator;
- уже открытые старые версии автоматически перезагружаются после активации нового Service Worker;
- HTML/JS/CSS теперь загружаются по схеме network-first, поэтому при наличии интернета приоритет всегда у свежей версии сайта;
- app.js и styles.css получают version query 11332 для дополнительного cache-busting;
- пользовательские настройки и введённые данные в localStorage не очищаются.

Логика расчётов v1.13.31 сохранена без изменений.

Версия 1.13.31: подпись «Сальса на баночку» заменена на «Сальса на таз». В разделе «Начинка» для каждой партии трюфеля теперь отдельно показаны «Сальса на таз» и «Сальса всего». Пороги 10/12/14/16/18/20 г не изменены.
- исправлен расчёт молока по чанам: партии больше не складывают своё молоко в чан;
- количество чанов определяется только общим молоком и лимитом чана;
- общее молоко равномерно распределяется между чанами без превышения лимита (например 605 кг -> 202/202/201);
- партии распределяются по чанам только как привязка/метка и не меняют объём молока;
- коэффициент лимонной кислоты каждого чана по-прежнему применяется к привязанным партиям Классики и Трюфеля.

Остальная логика версии 1.13.25 сохранена.

Трюфель: максимум общего в одном тазу по умолчанию изменён с 2067 г на 2100 г.
