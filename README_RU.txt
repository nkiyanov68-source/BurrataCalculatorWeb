Burrata Calculator Web 1.13.40

Версия 1.13.40:
- Проверка коробок теперь работает в обе стороны.
- Коробки должны давать ровно количество штук по формуле заявка × 8 без ОТК.
- Если коробок меньше или больше нужного количества, расчёт останавливается и показывается ошибка.
- Коробки используются только для распределения штук по партиям; общее количество по заявке они не меняют.
- Синхронизация лимонки из раздела «Чан» с главными результатами «Начинки» сохранена.
