Burrata Calculator Web 1.13.21

Версия 1.13.21: партии в первом разделе «Начинка» теперь можно не указывать — они рассчитываются автоматически по заявке. Можно заполнить только классику без трюфеля или только трюфель без классики. Раздел «Буррата» переименован в «Классика», при этом внутренняя логика расчётов и коробок сохранена.
