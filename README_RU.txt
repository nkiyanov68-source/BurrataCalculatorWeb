Burrata Calculator Web 1.13.39

Версия 1.13.39:
- Изменение коэффициента лимонки в разделе «Чан» сразу обновляет «Лимонка всего» и «Фермент всего» в «Начинка → Главные результаты» без повторного нажатия «Рассчитать».
- Общее количество штук всегда считается от заявки × 8 (с учётом текущей настройки requestToPieces).
- Коробки больше не задают общее количество штук: они используются только для количества партий и распределения рассчитанных штук по партиям.
- Если вместимости введённых коробок меньше количества штук по заявке, выводится ошибка.
- ОТК по-прежнему добавляется отдельно и в коробки не входит.
