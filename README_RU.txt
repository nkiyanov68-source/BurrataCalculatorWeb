Burrata Calculator Web 1.13.24

Версия 1.13.24: в разделе «Чан» добавлены отдельные настройки коэффициента лимонной кислоты. В настройках чана показывается ровно столько полей, сколько чанов получилось в расчёте; для каждого чана можно задать собственный коэффициент. Остальная логика 1.13.23 сохранена.
